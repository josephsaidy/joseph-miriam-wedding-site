RSVP FLOW:

1. Guest enters their full name.
2. Website normalizes the name.
3. Website searches the Supabase guest database.
4. If an exact match exists, show the matching guest/household.

   “Did you mean: [Guest Name]?”
6. If multiple close matches exist, show up to 3 suggestions.
7. If the guest confirms the match, show the RSVP form.
8. If no match is found, show:
   “We couldn’t find your name on the guest list. Please check the spelling or contact Joseph & Miriam.”
